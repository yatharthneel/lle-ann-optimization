# Results

This folder contains output plots generated by running the pipeline.

Run `python src/ann_pipeline.py` to generate `lle_ann_results.png` here.

## What gets generated

- **lle_ann_results.png** — 6-panel figure containing:
  1. Actual vs Predicted %Y (R² plot)
  2. Prediction Residuals
  3. Sensitivity: Acid Concentration
  4. Sensitivity: TOA Extractant %
  5. Sensitivity: DCM Modifier %
  6. ANN Architecture Diagram
